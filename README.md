# DAMMY Portfolio Website

Static portfolio website for DAMMY — Web Designer, Frontend Developer & Graphic Designer.

## Features

- Dark, premium black / off-white / electric lime / violet visual system
- Responsive layout for desktop, tablet and mobile
- Cursor-following glow
- Hero particle canvas
- Smooth internal navigation
- Scroll progress indicator
- Blurred navbar on scroll
- Scroll reveal animations
- Magnetic buttons
- Subtle 3D tilt cards
- Project filtering
- Interactive graphic-design lightbox
- Mobile navigation menu
- Contact buttons for Email, GitHub, Instagram and Call
- LinkedIn button marked as coming soon

## Run locally

Because this is a plain HTML/CSS/JS site, no npm install is required.

Open `index.html` directly in a browser, or use VS Code Live Server.

## Main files

- `index.html` — page structure and content
- `styles.css` — complete visual system and responsive styling
- `script.js` — interactions, animation and filters
- `assets/projects/` — project preview imagery
- `assets/designs/` — graphic-design gallery
- `assets/hero/` — reserved for future hero artwork

## Notes

Replace or add images in `assets/` as the portfolio grows. Update the project links and descriptions in `index.html` when a project changes.
